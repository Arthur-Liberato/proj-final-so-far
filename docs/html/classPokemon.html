Detailed Description

Representa os dados básicos de um Pokémon, conforme carregados de CSV.

Contém estatísticas base, tipos, habilidades, categorias, evoluções e características de concursos e resistências/fraquezas.

◆ fromCSV()

Pokemon Pokemon::fromCSV ( const std::string &  linha)
static

Cria um objeto Pokemon a partir de uma linha CSV.

A linha deve conter os campos na ordem: id, nome, tipo1, tipo2, hp, attack, spAttack, defense, spDefense, speed, abilities, category, evolutions, contestBeauty, contestCool, contestCute, contestSmart, contestTough, resistances, weaknesses.

Parameters
linhaLinha CSV com os valores separados por vírgula.

Instância de Pokemon populada conforme o CSV.
