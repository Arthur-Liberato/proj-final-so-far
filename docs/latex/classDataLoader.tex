\doxysubsection{Detailed Description}
Classe utilitária para carregar coleções de objetos a partir de arquivos. 

Todos os métodos retornam um std\+::vector com instâncias do respectivo tipo, lidas de um arquivo CSV cujo caminho é informado como parâmetro.
