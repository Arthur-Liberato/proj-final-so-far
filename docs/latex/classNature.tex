\doxysubsection{Detailed Description}
Representa a Natureza de um Pokémon. 

Cada instância de \doxylink{classNature}{Nature} contém\+:
\begin{DoxyItemize}
\item nome\+: o nome da natureza (por exemplo, "{}\+Hardy"{}, "{}\+Lonely"{}, etc.);
\item aumento\+: o atributo que receberá um bônus;
\item diminuicao\+: o atributo que receberá uma penalidade. 
\end{DoxyItemize}
