\doxysubsection{Detailed Description}
Representa uma berry com atributos de sabor e metadados. 

A classe \doxylink{classBerry}{Berry} encapsula os dados de uma berry (fruta) utilizada para melhorar atributos de um Pokémon. É possível criar uma instância a partir de uma linha CSV e recuperar cada atributo via getters.
