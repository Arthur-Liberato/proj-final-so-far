\doxysubsection{Detailed Description}
Representa um item que pode ser usado ou vendido no jogo. 

Cada \doxylink{classItem}{Item} possui um ID único, nome, categoria (como Potion, Poké Ball etc.), preço de compra/venda, raridade, efeito em concursos (contest) e uma descrição completa para uso no jogo.
