# Projeto final - Jogo pokemon

O Projeto consiste em um jogo Pokemon no estilo dress to impress, os monstros possuem atriutos bases como beleza, esperteza entre outros que podem ser melhorados ulitizando itens, pokeblocks e berries que são disponibilizadas ao usuário,feito isso são colocados frente a oponentes selecionados aleatoriamente para disputar o pokemon que possue o melhor conjunto de atributos. 

A logica do jogo é controlada na classe gamemanager,nela são inicializados os dados a partir da classe dataloader, são controladas as interações do usuário, aplicados os efeitos aos pokemons, avaliada a composição de cada monstro e feita a pontuação e a comparação do player com o oponente.

Listagem dos integrantes: Arthur Henrique Liberato Lima, Allan Victor Matos Temponi, Igor Maia Mendes Ribeiro e Paulo Cardoso
